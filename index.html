About MapReduce

MapReduce is the processing model of Hadoop. Big data is split into chunks, processed in parallel by mappers, grouped by key in the shuffle and sort phase, and finally combined by reducers into the final result.

  • Combiner: a mini-reducer that runs inside each mapper to cut down the data sent over the network.
  • Partitioner: decides which reducer gets which key, using hash(key) mod number of reducers.
  • Stop words: very common words (the, is, and) that are often removed before counting.

Hadoop vs Spark: Hadoop MapReduce writes intermediate results to disk after each stage, while Apache Spark keeps data in memory, which makes it much faster for iterative jobs.
